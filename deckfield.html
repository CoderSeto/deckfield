Import Team Roster

Copy a range of rows from Excel and paste below — one row per team, in this exact column order: Team Rank, DEX #, Region, Team Name, League Division, Accolades, Fatigue, Climate, PF, PA, DSCR, Skill Rating, Elo, Rating Grade, Region Record, League Record, Cup Record, Overall Record, Primary Type, Secondary Type. Excel copies cells as tab-separated text, so this just works with a normal paste.

Schedule Batch Settings

These apply to every matchup pasted below as one batch — paste a new list each time any of these change (e.g. a new round, or switching from Regional to Cup play).

Paste the Batch Settings row from deckfield_dashboard.html's Next Matchday tab to fill in everything below except Starting Timeslot and Games per Timeslot — those two you still set yourself. RDS Cup matchdays give you three separate rows (Ribbon/Dream/Star); apply and import each one as its own batch.

Import Matchups

Paste rows in this order: Away Team Rank, Home Team Rank, Adv. Adv is the modifier from the tail end of the Spread calculation — leave it blank for a normal game; it defaults to 0.

Region Climate

Paste rows in this order: Region, Region Climate. Region Climate is a number between 0 and 1 — it drives both the Climate Bonus (per team, by their own region) and this match's Weather (from the Home team's region, since that's the venue): Perfect ≥0.9, Good ≥0.8, Fair ≥0.65, Bad ≥0.5, Terrible <0.5.

Scheduled Matchups

Click Load → on any row to send that matchup to the Field tab — or use the shortcut below for whichever match is first in the list.

Match Results Log

Every completed game on the Field tab gets appended here automatically as one row, in the DECKFIELD ratings engine's add-results CSV format (comma-separated, header row included) — set Round # (and, for Cup games, Cup Name/ Bracket/Round #) on the Schedule tab before playing so it comes through filled in. Download it as a .csv file and run deckfield add-results <file> on it directly.
